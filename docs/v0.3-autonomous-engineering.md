## 自然語言接續（新增，待 CI 與實機驗收）
使用者可說「接續剛才中斷的工作」，Pi 可選用 `resume_interrupted_task`。只尋找目前工作目錄的未接續中斷任務；候選唯一才自動定位，多個候選必須釐清。接續前確認是否允許將原始需求和工具摘要帶入目前模型，沿用排他鎖、重新讀取紀錄後核對狀態及防重複接續。不自動重跑指令、不啟動 OS 程序、不直接還原。保留原有 Slash Command 作為備援。這是同一 Agent 的工具，不是新角色或工作模式；現有 journal 的啟發式判斷與鎖限制仍適用。

同一 Pi 行程內同時呼叫接續工具會拒絕重複請求；陳舊鎖清理使用額外排他鎖，避免另一個行程誤刪新鎖。若清理行程本身異常退出，`.resume.lock.reap` 可能需人工檢查，預設拒絕繼續而非冒險移除。

## 自動驗證證據（新增，待 CI）
觀察 Pi 原生 bash 工具事件，辨識少量獨立的 test/build/lint/typecheck 指令；不自行執行任意腳本、不更改權限、不要求使用者記住命令。`verification_status` 可讀本回合工具結果，任務結束時有實際變動或已辨識檢查會通知。Git 指紋包含 HEAD、index/working diff、status 與有限的 untracked 檔案雜湊；非原子快照，忽略檔、外部狀態、非 Git 專案及超出限制的資料可能無法驗證。只紀錄本回合、記憶體內的工具 ID 與結果，不持久化原始指令或輸出。CHECKS_OBSERVED_OK 是觀察結果而非完整品質通過；不認識的命令仍由模型依專案文件核對，沒有通用強制品質關卡或自動重試模型。新增 unit 與 real-Pi scripted RPC 驗證失敗、修復後成功及再次編輯過期。

## Checkpoint 自然語言預覽（新增，待 CI）
新增模型可自行呼叫的 `checkpoint_preview`：列出目前 Git 工作樹最近十筆具有可核對來源的完整 Checkpoint，依明確目標預覽還原檔案及應跳過的修改。新 Checkpoint 紀錄以實際 Git directory 的雜湊識別來源（不存放絕對路徑）；linked worktree 共用 refs，但模型預覽不跨工作樹，排除缺 post 及缺來源的舊紀錄。預覽沿用既有暫存 index 快照，只讀取／比對工作檔，但可能建立 Git objects，不改工作檔與正式 index。實際還原尚維持既有人工授權指令；暫不暴露自動寫入工具，因為現有還原在跨 Agent 同工作樹、symlink、並行檔案改動及中途 I/O 錯誤時仍有風險。既有指令的行為不變。測試新增 linked worktree 隔離與 real-Pi 預覽不改檔案回歸。

## 還原安全強化（待 CI）
還原前驗證工作樹來源、路徑、regular file 與目前 blob；不允許 symlink/junction/hardlink、危險路徑、未知 Git 模式或 stale plan，即使明確 force 仍不能覆蓋預覽後的新修改。先讀取舊內容並備份，再逐檔重新檢查；使用同目錄暫存檔替換普通檔案，刪除失敗不再忽略。重複還原建立獨立安全 Checkpoint；自動清理只針對當前工作樹的已完成新 Checkpoint，安全快照保留。仍非多檔案交易、非 OS 隔離鎖；中途失敗可能已改部分檔案，回報完成數及安全快照供檢查。模型仍只有預覽能力，真正還原維持人工授權的既有入口。

## 輕量化與狀態（待 CI）
驗證證據改成首次可能修改或執行指令時才取得基準，單純對話及已知唯讀工具不啟動 Git 指紋。每次指紋內 Git 子程序共用約 8 秒預算，逾時回報未知；檔案系統本身仍可能阻塞。Pi 原生狀態列顯示簡短繁中驗證狀態，不引入新的工作模式。Review Diff 每個差異區塊限制 12,000 字元，整體正文最多 30,000 字元，截斷明示並引導縮小 scope；details 旗標亦限制。這是輸出與 I/O 負擔優化，不是已證實的模型 token 或實機速度改善。既有 profile 保留已啟用的唯讀預覽／證據工具，仍不自動擴權。

CI 45767338613 的 checkpoint 回歸捕捉到二次 force 還原時已刪除檔案的 ENOENT；修正為預先檢查已不存在的 delete-created 動作並略過，真正刪除失敗仍停止且回報。新增已知其他 Pi 活動標記的拒絕測試，還原前及逐檔執行前檢查；不能偵測所有非 Pi 程序或未登記的 Agent，也不是跨程序鎖。
