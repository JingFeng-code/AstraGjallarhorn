## 自然語言接續（新增，待 CI 與實機驗收）
使用者可說「接續剛才中斷的工作」，Pi 可選用 `resume_interrupted_task`。只尋找目前工作目錄的未接續中斷任務；候選唯一才自動定位，多個候選必須釐清。接續前確認是否允許將原始需求和工具摘要帶入目前模型，沿用排他鎖、重新讀取紀錄後核對狀態及防重複接續。不自動重跑指令、不啟動 OS 程序、不直接還原。保留原有 Slash Command 作為備援。這是同一 Agent 的工具，不是新角色或工作模式；現有 journal 的啟發式判斷與鎖限制仍適用。

同一 Pi 行程內同時呼叫接續工具會拒絕重複請求；陳舊鎖清理使用額外排他鎖，避免另一個行程誤刪新鎖。若清理行程本身異常退出，`.resume.lock.reap` 可能需人工檢查，預設拒絕繼續而非冒險移除。

## 自動驗證證據（新增，待 CI）
觀察 Pi 原生 bash 工具事件，辨識少量獨立的 test/build/lint/typecheck 指令；不自行執行任意腳本、不更改權限、不要求使用者記住命令。`verification_status` 可讀本回合工具結果，任務結束時有實際變動或已辨識檢查會通知。Git 指紋包含 HEAD、index/working diff、status 與有限的 untracked 檔案雜湊；非原子快照，忽略檔、外部狀態、非 Git 專案及超出限制的資料可能無法驗證。只紀錄本回合、記憶體內的工具 ID 與結果，不持久化原始指令或輸出。CHECKS_OBSERVED_OK 是觀察結果而非完整品質通過；不認識的命令仍由模型依專案文件核對，沒有通用強制品質關卡或自動重試模型。新增 unit 與 real-Pi scripted RPC 驗證失敗、修復後成功及再次編輯過期。
